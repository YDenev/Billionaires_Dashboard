# Billionaires Statistics Dashboard

## Overview  
This project is a comprehensive dashboard built in **Microsoft Excel** to analyze and visualize billionaire statistics. The dashboard provides insights into the industries billionaires work in, their self-made status, gender distribution, and regional breakdown. Additionally, it compares the top 25 billionaires based on their age and net worth.

---

## Key Features  
- **Industry Breakdown:** Explore billionaire statistics by industry, categorized by self-made status, gender, and region.  
- **Age and Net Worth Comparison:** Analyze how the top 25 billionaires compare in terms of age and net worth.  
- **Interactive Navigation:** Utilize a user-friendly navigation bar with links between sheets and a contact option that directs to an email address.  
- **Dynamic Filtering:** Leverage slicers to apply filters for enhanced data exploration.  
- **Stylized Pivot Tables and Charts:** Employ custom-styled pivot tables and pivot charts for clear and professional data visualization.  
- **Statistical Insights:** Use Excel's data analysis tools to generate summary statistics.  
- **Data Preparation:** Apply advanced cleaning techniques and column standardization for accurate data representation.

---

## Techniques Used  
- Navigation bar with hyperlinks for seamless sheet transitions.  
- Contact option integrated with an email link.  
- Data cleaning and standardization for reliable analysis.  
- Excel's built-in **Data Analysis Tool** for statistical calculations.  
- Pivot tables and pivot charts with custom styles for detailed visual insights.  
- Cards and slicers to facilitate additional filtering and quick summaries.  

---

## Key Insights  
1. A significant majority of billionaires are **self-made** and **male**.  
2. Industry distribution shows variations by region, self-made status, and gender.  
3. The top 25 billionaires exhibit interesting trends when comparing **age** and **net worth**.
